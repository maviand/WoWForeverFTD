# WoWForever Resources

## Folder guide
- Forever_Roster_links.md, Forever_Roster_artifact_source.html: the interactive roster page and its source
- Warcraft_Forever_Roster.xlsx, Warcraft_Forever_Roster_OnePager.pdf: roster tables
- WF_Name_Reservation_Cheat_Sheet.pdf: reservation rules, order, checklist
- WF_Class_Guides.pdf: one page per character
- WF_Profession_Leveling_Planner.xlsx: skill tracker, coverage, campsites
- WF_Legacy_Points_Planner.xlsx: 65 account points, 16 per character
- WF_Beta_Findings_Log.xlsx: findings and open questions (beta ended Oct 23)
- WF_Guild_Names_Log.xlsx: empty template; needs your earlier guild-name sessions
- WF_NameCard_<Class>.png: name cards; WF_Art_<Class>_Transparent.png: cutout art
- WF_Sources_Archive.md: source links
