# WoWForeverFTD

Planning hub for the Future Divorced Committee in Warcraft Forever: roster, reservation day, launch night, planners, a patch notes analyzer and the La Fogata guild kit (Spanish).

Open `index.html` locally, or use the GitHub Pages site (see the repo's About link).

## Layout
- `index.html`: homepage linking everything
- `pages/`: the 15 single-file web pages (open any directly; no build step)
- `files/`: PDFs (one-pager, cheat sheet, class guides), Excel planners and logs, changelog, sources

## Notes
- Facts re-checked Oct 31, 2026 against [ForeverChanges](https://foreverchanges.pro/) (beta build 1.60.1.70707), a community tracker, not Blizzard. Hardcore and raid details are unconfirmed.
- Pages save your entries in your own browser (localStorage). Nothing is shared between visitors.
- `pages/La_Fogata_Guild_Prep_older_copy.html` is kept for reference; use `La_Fogata.html`.
- Fan-made. World of Warcraft is a trademark of Blizzard Entertainment.
